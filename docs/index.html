1. Fitting trigonometric and fixed-point math into one 340 x 160 um tile

A single Tiny Tapeout GF180MCU tile provides 51,967 um^2 of routable core area and 24 user signal pins. By replacing parallel array multipliers with an iterative shift-and-add CORDIC core, all four functional units fit in 37.7% of one tile.

2. Pin partitioning and two-cycle operand loading

With ui_in[7:6] dedicated to the 2-bit opcode, ui_in[5:0] carries a single signed 6-bit operand A (-32 to +31). Vectoring mode (opcode = 01) needs both x and y, so it uses a two-pulse handshake on START (uio_in[0]) gated by MODE (uio_in[1]).

Single-pulse operations (Rotate, MAC, PRNG/CRC)

  • Rotate (op = 00): Set ui_in[5:0] = A (angle in units of pi/64, from -32 = minus 90 degrees to +31 = plus 87.2 degrees). Pulse START high. On that rising clock edge, go_rot = 1 loads x0 = 311, y0 = 0, z0 = A << 4, and raises BUSY (uio_out[4]) for 8 clocks.
  • Saturating MAC (op = 10): Pulse START with MODE = 0 to add A (or 3*A when GAIN3 = 1) into acc[7:0], clamping at +127 or -128. Pulse START with MODE = 1 to clear acc.
  • LFSR and CRC-8 (op = 11): With MODE = 0, the Galois LFSR steps every clock while idle, or seeds {2'b01, A} on START. With MODE = 1, START feeds {2'b00, A} into the CRC-8 engine (or clears it when RSEL = 1).

Two-pulse vectoring handshake (op = 01)

  • Pulse 1 (Latch X, MODE = 0): Drive ui_in = {2'b01, x[5:0]}, hold MODE = 0, and raise START. At posedge clk, ld_vec_x = start & ~cbusy & op_vec & ~mode pulses high, latching xin <= a. BUSY remains low.
  • Pulse 2 (Load Y and Fold, MODE = 1): Pull START low for one clock to re-arm the edge detector (start_q <= 0), drive ui_in = {2'b01, y[5:0]}, set MODE = 1, and raise START. At posedge clk, go_vec = 1 combines xin and a through the +-90 deg pre-rotation network and asserts BUSY = 1 for 8 stages.
  • Result Readout (RSEL): After 8 clocks, BUSY drops low. With RSEL = 0, uo_out outputs cx[10:3] (scaled length 1.6467 * hypot(x, y)). With RSEL = 1, uo_out outputs cz[10:3] (angle in units of pi/128).

5. Key RTL mechanics and hardware verification notes

Arithmetic vs logical shift (>>>)

In Verilog-2005, >> always zero-fills the upper bits even on signed registers. In aariv_cordic_core, x and y are declared reg signed [10:0] and shifted with wire signed [10:0] ys = y >>> iter;. During cycle C7 of the vectoring trace, cy = -80 (11'h7B0) shifts right by 2 to produce -20 (11'h7EC) instead of +492, preserving two's complement sign extension across all quadrants.

Quadrant folding at +-90 degrees

The sum of the 8-entry arctangent table is 256 + 151 + 80 + 41 + 20 + 10 + 5 + 3 = 566 units of pi/1024, or 99.49 degrees. Without pre-rotation, vectors in Quadrants II and III with angles beyond +-99.49 degrees fail to converge. Inspecting v_fold = xin[5] rotates any x < 0 input by +-90 degrees into the right half-plane before stage 0 begins.

Time-multiplexed area savings

Unrolling 8 CORDIC stages combinationally requires 24 multi-bit adders in series. Reusing one iterative stage across 8 clock cycles with a 3-bit counter (iter) and an 8-entry LUT reduces aariv_cordic_core to 454 generic cells, letting the CORDIC core, MAC, LFSR, and CRC-8 route cleanly in 894 GF180MCU cells (37.7% of one tile) with 0 DRC errors.
